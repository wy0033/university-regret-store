## 这是什么

一家只卖"后悔药"的深夜便利店。你选一瓶对应心事的药（不挂科 / 敢说话 / 不内耗 / 去爱吧 / 和好如初 / 向前走 / 不将就 / 不熬夜），告诉店长你的年级、专业、正在烦恼的事和期望目标，"四年后的你"会亲手写一封回信给你——信的结局会跟着你的目标走（考研上岸、考公通过、拿到 offer），把"如果当初"变成"我真的做到了"。

## 功能特性

1. **8 瓶后悔药**：每瓶对应一类大学高频遗憾，含专属插画、关键词卡、四年必做清单
2. **双配方定制**：普通配方（一分钟速配）/ 进阶定制（昵称、遗憾小事、状态、心情 + 8 个模块各一个专属问题，信更懂你）
3. **AI 织信**：信件织入你的目标、遗憾、回答，结局随目标动态自洽（考研 / 考公 / 就业）
4. **配药体验**：研磨动画 + 对应名人名言、打字机回信、语音朗读（按性别选音色）
5. **深夜场**：22 点后自动切换夜间模式，附"早点休息"提醒
6. **药盒与历史**：收藏药方，药盒可点击查看每次配方的完整药方记录（信件 + 关键词卡 + 四年必做清单，清单可回看再勾选）
7. **分享**：提炼关键词卡 + 一键复制链接，直接发到微信打开
8. **断网可用**：纯前端单文件，素材本地化，本地双击即可演示

## 技术栈

1. 单文件 HTML + 原生 CSS/JS（无框架、无构建）
2. localStorage（药盒收藏、药方历史、深夜模式记忆）
3. Web Speech API（语音朗读）
4. 9 张 AI 生成日系治愈手账风插画（本地 assets/）

## 运行方式

直接双击打开 `index.html` 即可（依赖同目录 `assets/` 素材，转发请连同目录一起发送）。

## 作品理念

数据背后的场景洞察：大学生最常挂在嘴边的遗憾，不是"挂科"，而是"如果当初"——没说出口的话、没鼓起勇气的事、没早点睡的身体。产品把"后悔"转化为可行动的"药方"，用四年后的视角给当下的自己写回信，把情绪出口做成一场可交互的仪式。
