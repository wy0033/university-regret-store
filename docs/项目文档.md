## 一、项目概述

"作品名称"：大学后悔药便利店

"一句话介绍"：大学生遗憾太多、出口太少——选一瓶对应心事的后悔药，AI 化身"未来的你"写回信，把没说的话、没敢做的事，变成一张能行动的四年清单。

"作品形态"：外链演示（vibe coding 产出的单文件网页应用，纯前端、零依赖、双击即用、断网可用）

"体验链接"：Gitee 仓库 https://gitee.com/zhang-haoshan/regret-store（在线演示页部署中）

## 二、洞察与背景

大学生最常挂在嘴边的遗憾，不是"挂科"，而是"如果当初"：

1. "没说出口的话"：暗恋、道歉、感谢，当晚说不出口，就再也没机会说；
2. "没敢试的事"：举手发言、转专业、投简历，因为怕失败，所以先放弃；
3. "没早点睡的身体"：熬夜透支，把精力最好的四年过成了最累的四年；
4. "没分清的事"：内耗、将就、不敢离开不合适的专业与关系。

这些遗憾发生时往往很轻，轻到当晚说不出口就过去了；毕业时却很重，重到伴随很久。传统产品里：树洞只负责听、鸡汤只负责安慰、自律工具只负责打卡——"没有一款产品把"后悔"这种负面情绪，即时转化为可执行的"行动""。这正是本作品的切入点。

## 三、目标用户与问题

"目标用户"：在校大学生（大一新生到准毕业生），特别是正处于迷茫期、焦虑期、或刚结束一段遗憾的学生。

"要解决的三个问题"：

1. "无人倾听"：很多心事不想让身边人知道，缺一个私密、不评判的倾诉出口；
2. "无处安放"：深夜 emo 的情绪没有归属，只能靠刷手机熬过去；
3. "无行动出口"：知道后悔，却不知道下一步具体能做什么。

## 四、解决方案与核心创意

把"后悔药"做成一场可交互的仪式：用户选一瓶药、填下心事，"四年后的自己"（按年级映射为三年后/两年后/一年后/毕业后的自己）写回信，把遗憾翻译成三件本周就能做的小事。

"8 瓶后悔药"（每瓶对应一类大学高频遗憾）：

| 药 | 主题 | 承诺 |
|---|---|---|
| ① 不挂科 | 学业焦虑 | 期末不挂科，毕业不后悔 |
| ② 敢说话 | 表达恐惧 | 开口的那一刻，世界开始回应 |
| ③ 不内耗 | 精神内耗 | 卷要卷得清醒，躺要躺得心安 |
| ④ 去爱吧 | 心动/失恋 | 有些话现在不说，四年后会后悔 |
| ⑤ 和好如初 | 人际修复 | 夜聊比熬夜更治愈 |
| ⑥ 向前走 | 毕业迷茫 | 毕业那天，你不慌 |
| ⑦ 不将就 | 方向选择 | 转专业不犹豫，选路不后悔 |
| ⑧ 不熬夜 | 身体透支 | 早睡早起，四年不掉队 |

"双配方定制"：

1. "普通配方"：一分钟速配，收集年级、专业、期望目标、正在焦虑的小事；
2. "进阶定制"：额外收集昵称、遗憾小事、当前状态、心理情况，以及 8 个模块各一个专属问题（复习状态、发言习惯、内耗场景、心动遗憾、室友卡点、未来状态、专业想法、熬夜原因），生成更懂你的专属信件。

"AI 织信与动态结局"：

1. 以"未来的你"视角写信，织入用户的昵称、目标、遗憾、专属问题回答；
2. 结局随期望目标动态自洽：填考研 → 收到录取通知；填考公 → 通过笔试面试；填就业 → 拿到 offer；
3. 视角随年级调整：大一收到"三年后的你"的回信，大二"两年后"，大三"一年后"，大四"刚毕业的你"，信内固定时间点（大二下学期、大三秋天、体测等）也随年级灵活变化；
4. 信件全部中性化表达，不预设性别，兼顾所有用户。

"关键词卡与四年必做清单"：每瓶药生成一张关键词卡（专业、年级、期望目标、状态等）+ 三件本周可执行的小事，把"后悔"变成"行动"。

## 五、主要功能

1. "8 瓶后悔药"：专属插画、承诺语、关键词卡、四年必做清单；
2. "双配方定制"：普通速配 / 进阶深度定制（8 模块专属问答）；
3. "AI 织信"：目标联动结局（考研/考公/就业），年级联动视角；
4. "配药仪式"：研磨动画 + 每瓶专属名人名言（华罗庚、苏轼、鲁迅等）+ 打字机回信 + 语音朗读（按性别匹配音色）；
5. "药盒与历史"：收藏药方，可点开查看每次完整配药记录（信件 + 关键词卡 + 清单），清单可回看再勾选；
6. "深夜场"：22 点后自动切夜间模式，常驻"早点休息"提醒，深夜版文字配色优化保证可读性；
7. "分享"：一键提炼关键词卡 + 复制链接，可直接发到微信打开。

## 六、使用流程

推开店门（暖光插画开场）→ 货架选一瓶药 → 填方（普通/进阶两种入口）→ 配药动画（研磨 + 名言）→ 收到"未来的你"回信（插画 + 打字机信件 + 语音朗读 + 关键词卡 + 四年必做清单）→ 收藏进药盒 / 分享给朋友 / 按清单行动。

## 七、技术实现

"技术栈"：

1. 单文件 HTML + 原生 CSS/JS（零框架、零依赖，兼容桌面与移动端）；
2. localStorage：药盒收藏、药方历史、深夜模式记忆；
3. Web Speech API：语音朗读；
4. 9 张 AI 生成日系治愈手账风插画（门面 + 8 瓶药场景）。

"AI 使用与人机协作"（vibe coding 过程）：

1. AI 参与：插画生成（门面与 8 瓶药场景）、信件文案与结局逻辑的规则设计、功能迭代的代码补丁；
2. 人工主导：产品方向、8 瓶药选题与文案、交互体验打磨、效果验收；
3. 制作过程沉淀 28 个可复现脚本（scripts/ 目录：分段构建、图片路径静态化、13 轮功能迭代补丁、8 个 bug 修复、4 个逻辑验证脚本），完整记录人机协作链路，可复现、可审计。

## 八、交互与体验设计

1. "五屏沉浸流程"：开场 → 选药 → 填方 → 配药 → 成品，每一步有场景化叙事承接；
2. "信件仪式感"：打字机逐字回信，署名始终是"X 年后的你"；
3. "无障碍与适配"：深夜模式可手动切换、键盘焦点可见、移动端全适配；
4. "情绪细节"：深夜 22 点后自动进入夜间场并提醒早点休息，贴合大学生深夜 emo 的真实场景。

## 九、创新点与差异化

1. ""后悔药"叙事"：把负面情绪"后悔"转化为可购买、可服用、可收藏的产品意象，天然具备传播力；
2. "未来视角回信"：AI 扮演"未来的你"而非第三方，既有同理心又有说服力；
3. "情绪 → 行动闭环"：不是单纯安慰，每封信都带三件本周可做的小事，形成"配药—行动—复盘"闭环；
4. "目标/年级双联动"：信件结局跟随期望目标、时间视角跟随年级，让"定制"不流于表面；
5. "零门槛体验"：无注册、无加载、双击即玩，30 秒完成一次完整配药。

## 十、作品理念与价值

大学生是"如果当初"发生频率最高的群体，也是改变机会最多的群体。本作品不贩卖焦虑，不提供说教，只提供一个深夜可以走进的小店：把遗憾接住，把情绪出口，把行动交还。"它不是工具，是情绪出口。"
